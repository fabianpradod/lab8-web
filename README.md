# Password Strength Meter

Aplicación de React que muestra la fortaleza de una contraseña en tiempo real.

## Instalación

```bash
bun install
```

## Correr las pruebas

```bash
bun run test
```

## Correr el proyecto

```bash
bun dev
```

## Flujo de trabajo TDD

Este proyecto fue desarrollado siguiendo Test Driven Development:

1. Las pruebas fueron escritas primero, antes de que existiera cualquier implementación.
2. Las pruebas fallaron inicialmente porque no había implementación.
3. Se hizo un commit con todas las pruebas fallando.
4. Se implementó la función de lógica pura, haciendo pasar esas pruebas.
5. Se implementó el componente de React, haciendo pasar todas las pruebas restantes.
6. No fue necesario refactorizar ya que la implementación estuvo limpia desde el inicio.
